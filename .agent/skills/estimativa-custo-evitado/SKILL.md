# Skill — Estimativa de custo evitado (sem falsa precisão)

## Objetivo

Apoiar a Nota de ROI (Fase 5) sem inventar números.

## Método

- Trabalhar com faixas e cenários (pessimista/base/otimista).
- Deixar explícito:
  - quais variáveis são conhecidas
  - quais são suposições
  - qual dado falta para refinar

## Saída

- Tabela com variáveis, fonte (ou lacuna), faixa e sensibilidade.
- Texto curto: o que muda a decisão mesmo com incerteza.
