# Skill — Triagem e priorização de intervenções

## Objetivo

Priorizar `I-XX` para execução e para aprofundar evidências.

## Critérios (ajustáveis)

- Risco mitigado (jurídico/INSS/contrato/operação)
- Impacto esperado
- Viabilidade (tempo, custo, governança)
- Força da evidência disponível
- Dependência de cliente/contrato

## Saída

- Top N intervenções com justificativa curta
- “Backlog” (as demais)
- Recomendações de quais evidências coletar para subir intervenções do backlog
