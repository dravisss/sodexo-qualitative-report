# Workflow — Fase 6: Checagem final

## Entrada

- `intervencoes/` (dossiês)
- `evidencias/indice/moc.md`
- Matriz consolidada (se existir)

## Saída

- Lista de pendências e correções antes de finalizar

## Checklist

- IDs de intervenções consistentes com doc 08.
- Cada dossiê tem:
  - evidências rastreáveis
  - força da evidência
  - lacunas acionáveis
  - pré-condições
- MoC cobre todos os PDFs/blobs relevantes.
- Matriz é derivada dos dossiês (sem dados “soltos”).
- Cobertura: Cajamar + Guarulhos Food + Guarulhos FM.
