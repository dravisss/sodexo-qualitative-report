# Workflow — Fase 5: Proposta de visualizações

## Entrada

- Dossiês (ou subset)

## Saída

- 3–10 specs curtas usando `.agent/schemas/visualizacao-spec.template.md`

## Passos

1. Liste as perguntas decisórias mais importantes.
2. Para cada pergunta, proponha uma visualização.
3. Defina dados de entrada e regras de interpretação.
4. Aponte quais dossiês/evidências sustentam.
