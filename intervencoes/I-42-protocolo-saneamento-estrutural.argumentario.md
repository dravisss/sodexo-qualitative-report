# Argumentário Executivo: I-42 — Protocolo de Saneamento Estrutural

## 1. O Problema (A Tensão)
- **O que acontece:** O sistema de bônus atual pune o gestor que gasta para resolver problemas estruturais (EPI, Manutenção, Demissão de Tóxicos).
- **A consequência:** "Gestão por Gambiarra". Os problemas são empurrados com a barriga para "salvar o mês", criando passivos gigantescos (multas, turnover, processos) no longo prazo.
- **Citação:** "Prefiro perder um funcionário bom do que perder minha meta de margem." (Incentivo Perverso)

## 2. A Solução (A Intervenção)
- **O que é:** Criar uma linha de **"Investimento de Saneamento"** na DRE Gerencial ("Shadow P&L").
- **Como funciona:**
    - O custo entra no P&L da empresa, mas é **neutralizado** para o cálculo do bônus do gestor.
    - **Governança:** Só vale se aprovado tecnicamente (Segurança/Qualidade) e com evidência documental.
    - **Trava:** Se o problema voltar em 6 meses, o custo volta para o bônus com multa.

## 3. Viabilidade (Por que funciona?)
- **Financeira:** O custo de *não fazer* (processos trabalhistas, turnover de 119%, multas) é muito maior que o custo do saneamento pontual.
- **Operacional:** Desbloqueia a decisão na ponta. O GU não precisa mais escolher entre "fazer o certo" e "pagar as contas".
- **Cultural:** Mensagem clara de que a empresa valoriza a sustentabilidade da operação acima do lucro de curto prazo.

## 4. Objeções e Respostas

| Objeção | Resposta |
| :--- | :--- |
| **"Vai virar farra de gastos."** | Não. A aprovação exige laudo técnico e validação de terceiros (não apenas do chefe imediato). Além disso, a "Trava de Reincidência" pune o abuso. |
| **"Por que não simplesmente aumentar o budget?"** | Porque orçamento solto vira gasto operacional. O "Saneamento" carimba o dinheiro para resolver passivos específicos, garantindo que o recurso vá para onde precisa. |
| **"É complicado de calcular."** | É uma linha extra na planilha de apuração de bônus. O sistema ERP já permite centros de custo específicos. |
